## Selected projects

- **Incident Atlas.** A FastAPI and LangGraph assistant for versioned runbooks. Expected-source citations improved from 7/11 to 11/11 answerable cases in a 14-case synthetic evaluation. [Code and evaluation](https://github.com/nischay1277/langgraph-nischay)
- **Adaptive Video Streaming.** A PyTorch reinforcement-learning policy that selects from six video bitrates, with a browser demo that compares playback on simulated network traces using FFmpeg-encoded video. [Code and demo guide](https://github.com/nischay1277/adaptive-streaming-rl)
- **Database Drift Detective.** A PostgreSQL and SQLite testing tool that reduced a historical Open WebUI search failure to one synthetic chat and one SQL query. [Code and case study](https://github.com/nischay1277/db-drift-detective)
- **CrashLab.** A fault-injection workbench for testing worker crashes, lost HTTP responses, and retries. In a local PostgreSQL concurrency test, duplicate delivery to two workers produced one durable artifact. [Code and test scenarios](https://github.com/nischay1277/crashlab)
- **Tamil Speech to FIR Drafting.** An officer-assisted prototype that turns Tamil and Tamil-English audio into structured drafts, with a React and TypeScript review interface. [Code and API documentation](https://github.com/nischay1277/fir-tN)
